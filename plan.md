# План проєкту «ШоПоСвітлу»

## Підхід до реалізації

Репозиторій розділено на статичний PWA-клієнт для Vercel (`public/`) та окремий Cloudflare Worker (`worker/`). Адресу розгорнутого Worker власник задає один раз у публічному `public/config.js`; секретів у фронтенд-конфігурації немає. Кінцевий користувач вводить лише своє посилання на Telegram-канал, вибирає чергу/день та інтервал оновлення. Клієнт зберігає ці параметри у `localStorage`. Worker нормалізує джерело тільки до `t.me/s/<username>`, читає максимум п'ять останніх дописів, вибирає найновіший графік на сьогодні й завтра, зберігає дані у KV та віддає JSON через CORS. Cron оновлює типовий канал раз на п'ять хвилин; налаштування інтервалу в PWA керує частотою запитів клієнта. Додано ручне оновлення, оновлення під час старту й повернення у вкладку, стани завантаження/помилки, PWA offline shell та тести парсера.

Структура: `public/index.html` — доступний інтерфейс; `public/css/style.css` — адаптивний вигляд та анімації; `public/js/app.js` — вибір графіка, стани, налаштування й оновлення; `public/js/api.js` — запити до Worker; `public/js/timeline.js` — обчислення статусу та шкала; `public/config.js` — одноразово налаштовувана публічна адреса Worker; `public/manifest.json`, `public/sw.js`, `public/icons/` — PWA; `worker/index.js` — API, парсер і Cron; `worker/index.test.js` — тести; `worker/wrangler.toml` — Cloudflare bindings та Cron. `README.md` описує одноразове налаштування Cloudflare і Vercel.

## Дизайн

- **Design Movement:** Неонова утилітарна панель у дусі нічного міського енергетичного диспетчера, адаптована з наданого референсу.
- **Core Principles:** Статус видно з першого погляду; важливе має контраст; мобільна взаємодія зручна для великого пальця; помилки не маскуються під актуальні дані.
- **Color Philosophy:** Глибокий синьо-чорний фон нагадує ніч; електричний блакитний позначає мережу й дії; бурштиновий — відключення; зелений/червоний — поточний стан за планом.
- **Layout Paradigm:** Три окремі екрани з нижньою панеллю: великий статус на «Стан», шкала та список інтервалів на «Графік», джерело й налаштування на «Джерело».
- **Signature Elements:** Пульсуюча SVG-лампа, тонкі світні контури, шкала доби зі світловим маркером «Зараз».
- **Interaction Philosophy:** Черга й день змінюються без перезавантаження; мережевий запит має явний стан завантаження; налаштування зберігаються на пристрої.
- **Animation:** Повільне дихання лампи лише для стану «світло є»; короткий індикатор завантаження; `prefers-reduced-motion` вимикає декоративні цикли.
- **Typography System:** Системний гротеск з українською підтримкою; табличні цифри; чітка ієрархія заголовків та мікропідписів.
- **Brand Essence:** Показує мешканцям громади, коли за оприлюдненим графіком має бути електроенергія; виразний, практичний, спокійний.
- **Brand Voice:** Коротко й чесно: «Світло є за графіком»; «Не вдалося дістатися каналу — перевірте джерело».
- **Wordmark & Logo:** Текстова назва «ШоПоСвітлу» поруч із контурною блискавкою/лампою.
- **Signature Brand Color:** Електричний блакитний `#16B8FF`.

## Межі

Застосунок показує оприлюднений плановий графік, а не підтверджений стан електромережі. Worker визначає дати за `Europe/Kyiv`; індикатор поточного часу використовує локальний час пристрою. Реальне підключення до зовнішніх сервісів потребує одноразового створення KV namespace, розгортання Worker та запису його адреси в `public/config.js`.
