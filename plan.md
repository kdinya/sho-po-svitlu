# План проєкту «ШоПоСвітлу»

## Підхід до реалізації

Репозиторій розділений на статичний PWA-клієнт для Vercel (`public/`) та окремий модуль Cloudflare Worker (`worker/`). Браузер зберігає URL Worker, публічне посилання на Telegram-канал, вибрану чергу й інтервал оновлення у `localStorage`; Worker завжди самостійно нормалізує адресу до `t.me/s/<channel>`, читає не більше п'яти останніх дописів, визначає графіки на сьогодні та завтра, зберігає результат у Cloudflare KV і віддає його через CORS API. Cloudflare Cron оновлює канал за замовчуванням кожні п'ять хвилин; налаштування частоти у клієнті керує інтервалом опитування Worker з пристрою користувача. Додано ручне оновлення, оновлення при запуску та поверненні у вкладку, кешування останнього результату, PWA manifest/service worker, офлайн-оболонку, локальні тести парсера й інструкції підключення Cloudflare/Vercel.

Структура: `public/index.html` — доступний інтерфейс; `public/css/style.css` — адаптивна темна тема й анімації; `public/js/app.js` — стан, налаштування, картки й оновлення; `public/js/api.js` — запити до Worker; `public/js/timeline.js` — шкала й обчислення статусу; `public/manifest.json`, `public/sw.js`, `public/icons/` — PWA; `worker/index.js` — API, Telegram-парсер і Cron; `worker/index.test.js` — тести; `worker/wrangler.toml` — конфігурація Worker, KV і Cron. `README.md` пояснює налаштування сервісів, а `vercel.json` задає статичний output.

## Дизайн

- **Design Movement:** Неонова утилітарна панель у дусі нічного міського енергетичного диспетчера, адаптована з наданого референсу.
- **Core Principles:** Статус електропостачання видно з першого погляду; важлива інформація має чіткі контрастні рівні; мобільна взаємодія оптимізована для великого пальця; помилки каналу не маскуються під застарілі дані.
- **Color Philosophy:** Глибокий синьо-чорний фон відтворює нічне небо; електричний блакитний позначає мережу та доступну дію; теплий бурштиновий означає заплановане відключення; зелений/червоний — зрозумілий поточний стан.
- **Layout Paradigm:** Заголовок із великим статусом переходить у горизонтальну шкалу доби, після якої йдуть два компактні модулі — план і джерело. На вузьких екранах модулі природно складаються в одну вертикальну стрічку.
- **Signature Elements:** Пульсуюча SVG-лампа, тонкі світні контури карток, шкала 24 годин із світловим маркером «Зараз».
- **Interaction Philosophy:** Перемикання черги й дати оновлює представлення миттєво; мережевий запит має явний стан завантаження; налаштування відкриваються в компактній доступній панелі; відкриття джерела не губить контекст.
- **Animation:** Повільне дихання світла лише для ввімкненої лампи; короткий рух для завантаження та зміни дня; `prefers-reduced-motion` вимикає декоративні цикли.
- **Typography System:** Системний гротеск з українськими гліфами; табличні цифри для часу; великі заголовки та компактні підписи для швидкого сканування.
- **Brand Essence:** Показує мешканцям громади, коли за оприлюдненим графіком має бути електроенергія; виразний, практичний, спокійний.
- **Brand Voice:** Коротко й чесно: «Світло є за графіком»; «Не вдалося дістатися каналу — перевірте джерело».
- **Wordmark & Logo:** Назва набрана власним текстовим словом «ШоПоСвітлу» поруч із контурною блискавкою/лампою, без зовнішнього логотипу.
- **Signature Brand Color:** Електричний блакитний `#16B8FF`.

## Межі

Застосунок показує саме оприлюднений плановий графік, а не підтверджений стан мережі: фактичні відключення можуть не збігатися з повідомленням. Обчислення статусу використовує локальний час пристрою; розбір дати для Worker — час Europe/Kyiv. Vercel і Cloudflare розгортаються у власних акаунтах користувача після додавання Worker URL та створення KV namespace.
